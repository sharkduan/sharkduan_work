# Spec: Verification Matrix

## Objective

Tie every development specification to checkable evidence. This document prevents purely narrative implementation by requiring each module to prove its contract through schemas, fixtures, commands, reports, or conservation equations.

## Checkpoints

### Data Release Gate

- All three required sources report `complete_for_v1: true`.
- `complete_for_v1` is a per-source raw manifest coverage signal; the release gate is the all-source ETL quality report after accepted, rejected, and conflict records reconcile.
- Accepted, rejected, and conflict records reconcile.
- Candidate coverage, split totals, and visual check status/blocking totals reconcile in the ETL quality report.
- Rule calibration sheet and rule table are present.
- Edge candidates and splits pass schema and leakage checks.
- Visual check `pending`, `fail`, and `needs_rule_review` statuses all block sampled records from first-core release until resolved; only `pass` is non-blocking.

### Model/Training Gate (Checkpoint B)

- `python -m covalent_design.model.inspect_batch --records <records.jsonl>` outputs deterministic JSON for fixture records.
- `python -m covalent_design.model.forward_smoke --config configs/covalent_model_smoke.yml` logs PMDM + covalent output shapes.
- `python -m covalent_design.training.train --config configs/covalent_train_smoke.yml` produces `train_metrics.jsonl` containing:
  - All 6 loss components (pmdm_position_loss, pmdm_atom_loss, covalent_edge_loss, covalent_bond_type_loss, covalent_geometry_loss, family_aux_loss).
  - `EdgeDenominators` (10 fields), `MaskAudit` (15 fields), per-family/timestep strata.
- Fixture coverage: natural positive, forced positive, zero negatives, pending geometry, pending SMARTS, missing chemical state, Q2, empty_radius_window.
- No rejected, conflict, or multi-linkage records enter training when `first_core_only=True`.
- Forced-positive and Q2 stratification fixtures pass.
- `python -m compileall -q scripts src` passes.

### Inference/Evaluation Gate (Checkpoint C)

- All 13 `REQUEST_*` validation error fixtures pass. CLI `--rules` flag and default rule table path tested. Structure reader (pure Python, PDB/mmCIF) tested.
- `SamplingSystemFailure` fixtures: crash, OOM, timeout, retry_exhausted,
  checkpoint_load_failed, sampler_invariant_violation.
- Valid and invalid `CovalentGenerationResult` fixtures with complete diagnostics (~30 fields).
- `run_manifest.yml` conservation: `accepted_request = attempted + sampling_system_failure`.
- mmCIF export valid + export-failure fixtures via project-owned writer/adapter boundary.
- `python -m covalent_design.evaluation.summarize_results --manifest <run_manifest.yml>` — manifest-first, writes `evaluation_summary.json` beside manifest, prints summary to stdout, all 6 conservation equations pass.
- `python -m covalent_design.evaluation.check_denominators --manifest <run_manifest.yml>` — manifest-first, prints validation receipt to stdout (no file write).
- Docking protocol manifest validation passes; QuickVina2-only fixture → `covalent_docking_score = null`.
- Per-split, per-family stratified reports (Task 33) with protein-cluster and scaffold primary metrics.
- `python -m compileall -q scripts src` passes.
